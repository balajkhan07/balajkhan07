# Balaj Khan — Personal Portfolio

Senior Full Stack Engineer portfolio. Live at **https://balajkhan07.github.io**

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide Icons

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Live URL

Repo should be named **`balajkhan07.github.io`** so GitHub serves the site at:

**https://balajkhan07.github.io**

Vite `base` is `/`.

## Deploy

1. Push to `main`
2. **Settings → Pages → Source: GitHub Actions**
3. Wait for **Deploy to GitHub Pages**
4. Open https://balajkhan07.github.io

Content edits live in **`src/config/site.ts`**.
